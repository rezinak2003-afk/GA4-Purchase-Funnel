# Project 1 quality checklist (from the build guide)

- [ ] Definitions for session, funnel steps, counting rule and channel are written in README.
- [ ] Session sanity checks pass; results are recorded.
- [ ] Funnel, device, first-touch channel and landing-type outputs are reproducible from numbered SQL files.
- [ ] Transaction ID duplication/missingness has been checked; the shared purchase transaction table is built only after confirming the deduplication rule is valid.
- [ ] Largest qualified gap is sized at 25%, 50% and 100% closure, with arithmetic shown.
- [ ] Significance check or confidence interval supports the headline comparison.
- [ ] Dashboard has no more than three pages, finding-led titles, filters and caveat footer.
- [ ] One-page recommendation PDF contains only actual results and is linked in README.
- [ ] README begins with the recommendation and a real screenshot.
- [ ] Dashboard link works in a private browser window.
- [ ] Two-minute walkthrough is recorded and linked.
- [ ] Every resume number can be re-derived from the repository.
- [ ] `git status` checked; no raw data or secrets staged.
